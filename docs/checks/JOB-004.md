ID: JOB-004

Name:
No timeout configured

Severity:
WARNING

Why:
Without a timeout, a stuck run can occupy a cluster (and accrue cost) indefinitely instead
of failing and freeing resources.

Detection:
`timeoutSeconds == 0` or unset (`null`).

Recommendation:
Configure a run timeout so a stuck run doesn't occupy compute indefinitely.

Can auto-fix:
No
