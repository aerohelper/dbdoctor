ID: JOB-001

Name:
Retry policy not configured

Severity:
WARNING

Why:
A transient failure (a brief cluster blip, a flaky upstream dependency) will fail the whole
job run outright if no task has a retry policy configured.

Detection:
No task on the job has `maxRetries > 0`. Jobs whose task list dbdoctor couldn't evaluate are
skipped rather than flagged.

Recommendation:
Configure task-level retries so transient failures don't fail the whole job run.

Can auto-fix:
No
