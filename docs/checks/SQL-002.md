ID: SQL-002

Name:
Oversized warehouse

Severity:
WARNING

Why:
Warehouses sized larger than actual query load requires waste cost. This is deliberately a
simple size-tier cap, not an attempt at intelligent sizing based on actual usage data —
dbdoctor doesn't have reliable utilization data wired up yet (see the project's phase plan).

Detection:
`clusterSize` is one of `Large, X-Large, 2X-Large, 3X-Large, 4X-Large` (default tier set,
configurable).

Recommendation:
Review whether this size is actually needed based on query load.

Can auto-fix:
No
